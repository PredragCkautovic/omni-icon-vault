# Custom icons

Drop your own `.svg` files anywhere in this folder, then rebuild the local index:

```bash
omni-icons rebuild
```

Custom files appear as the **My Custom SVGs** pack and are available in the Web UI, Figma plugin, CLI/API, and project exports.

Folders become part of the canonical ID, so you can keep project or category-specific sets organized:

```text
custom-icons/
├── automotive/
│   └── engine.svg
└── company/
    └── logo-mark.svg
```
