Omni Icon Vault 4.1.1 hotfix

Apply over your existing Git checkout:

  cd ~/Documents/omni-icon-vault
  unzip -o ~/Downloads/Omni-Icon-Vault-4.1.1-Repo-Hotfix.zip -d .

  python -m unittest discover -s tests -v
  python -m compileall -q install.py uninstall.py omni.py tools scripts tests

  python install.py
  ~/.local/bin/omni-icons doctor
  ~/.local/bin/omni-icons open

  omni-icons doctor
  omni-icons open
