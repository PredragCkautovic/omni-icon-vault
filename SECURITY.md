# Security policy

Please report security issues privately through GitHub's **Security → Report a vulnerability** feature if enabled on the repository. Do not include secrets or exploit details in a public issue.

Omni's local API is intended to bind only to `127.0.0.1`. Archive extraction and favicon SVG processing include safety checks, but reports about bypasses, unsafe URL handling, path traversal, arbitrary file writes or local API exposure are especially welcome.

Supported branch: the latest stable `4.x` release.
